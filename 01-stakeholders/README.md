# 01 · Стейкхолдеры

## Задача

Выявить заинтересованные стороны будущей системы. Для каждого стейкхолдера выяснить его интересы, потребности и проблемы.

## Что сделано

**Доставка**
- **Каталог стейкхолдеров.** Выявил 12 заинтересованных сторон с указанием категории и уровня контакта с системой.
- **Луковичная диаграмма.** Построил диаграмму с распределением стейкхолдеров по слоям взаимодействия с системой.
- **Анализ стейкхолдеров.** Составил таблицу с описанием интересов, потребностей и проблем стейкхолдеров.
- **Глоссарий.** Пополнил до 15 терминов.
