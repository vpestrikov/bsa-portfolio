# 04 · Модель данных

## Задача

Описать предметную область через данные: какие сущности хранит система, какие у них атрибуты и как сущности связаны.

## Что сделано

**Доставка**
- **Выявление сущностей.** Определил 7 сущностей с назначением и ключевыми атрибутами
- **Словарь данных.** Составил словарь данных для 12 сущностей с мнемоникой, описанием, типом данных и обязательностью.
- **ER-диаграмма.** Построил логическую модель данных с указанием связей между сущностями.

**Барбершоп**
- **Выявление сущностей.** Определил 7 сущностей с назначением и ключевыми атрибутами
- **CRUD-анализ.** Проверил полноту операций Create/Read/Update/Delete для 7 сущностей с указанием ролей и действий.
- **Словарь данных.** Составил словарь данных для 16 сущностей с мнемоникой, описанием, типом данных и обязательностью.
- **ER-диаграмма.** Построил логическую модель данных с указанием связей между сущностями.
