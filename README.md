# Портфолио бизнес- и системного аналитика

Я Владислав Пестриков, учусь на треке «Бизнес- и системный анализ» в Школе 21. Здесь собраны мои учебные проекты по бизнес- и системному анализу. В репозитории представлены результаты выполнения; исходные условия заданий и учебные материалы не включены. Проекты выполнены на двух сквозных кейсах.

## Кейсы

**Служба доставки.** Проектирование системы для стартапа курьерской доставки. Цель — сократить время от поступления заказа до его принятия курьером и убрать ручную работу.

**Онлайн-запись в барбершоп.** Проектирование системы онлайн-записи для сети барбершопов. Цель — расширение клиентской базы и автоматизация рутинных операций менеджера.
