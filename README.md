# Портфолио системного аналитика

Я Владислав Пестриков, учусь на треке «Бизнес- и системный анализ» в Школе 21. Здесь собраны мои учебные проекты: работа со стейкхолдерами, требования, модели данных и диаграммы. Все проекты сделаны на двух сквозных кейсах. Ищу стажировку на позицию системного аналитика.

## Кейсы

**Служба доставки.** Студенты запускают стартап доставки. Магазины и кафе передают заказы, курьеры сами выбирают свободные заказы в мобильном приложении и отмечают этапы доставки, диспетчер следит за статусами и переназначает заказы, бухгалтерия рассчитывается с курьерами. Сейчас заказы приходят по телефону и в мессенджерах, статусы выясняются обзвоном. Нужна единая система, в которой у каждого заказа одна запись для всех участников.

**Онлайн-запись в барбершоп.** Сеть барбершопов хочет, чтобы клиенты записывались онлайн: выбирали услугу, мастера и свободное время, с регистрацией или без неё. Система сама напоминает клиентам о визите. Менеджер ведёт расписание мастеров и услуги, принимает оплату, клиенты оставляют отзывы. Цель — расширить клиентскую базу и снять с сотрудников ручную работу.

## Навыки

### Анализ требований
- Stakeholder Analysis: каталог стейкхолдеров, луковичная диаграмма, интересы, потребности и проблемы
- Анализ процессов As Is / To Be и решения для проблем стейкхолдеров
- Бизнес-требования и границы системы: документ Vision (концепция)
- Сбор источников информации: нормативные акты, аналоги
- Ведение глоссария проекта

### Выявление требований
- Ролевая игра
- Мозговой штурм
- Семинар
- Интервью с AI-ассистентом и проверка его ответов

### Моделирование систем
- Context Diagram
- DFD
- Swimlane Diagram
- State Diagram и State Table

### Работа с данными
- Сущности и атрибуты
- CRUD Matrix
- Data Dictionary
- Логическая модель данных (ERD), PK/FK
- Статусные модели и жизненный цикл объектов
